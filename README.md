# AI-based-multi-disease-analysis-system
### Heart Disease & Diabetes Risk Prediction using Machine Learning

## 📌 About Project

-AI Health Risk Analysis System is a Machine Learning based project that predicts the risk probability of **Heart Disease** and **Diabetes** using user health information.
-The main purpose of this project is to analyze medical data and provide an early risk prediction using AI/ML models.
-This project is developed for educational purposes and should not be considered as a medical diagnosis system.

# Features

# Heart Disease Prediction

* Predicts the possibility of heart disease.
* Takes user health details as input.
* Provides risk prediction result.

# Diabetes Prediction

* Analyzes diabetes-related health parameters.
* Predicts diabetes risk probability.

# Machine Learning Based Analysis

* Uses trained ML models.
* Processes user data.
* Generates prediction based on patterns learned from datasets.

# How It Works

1. User enters health-related information.

2. Data goes through preprocessing.

3. Trained machine learning model analyzes the data.

4. Model predicts disease risk.

5. Result is displayed with probability.
